# 📱 Chefs Menu Manager

## App Description:
The Chefs Menu Manager App is a mobile application developed using React Native and Expo.
The application allows chef Christoffel to view the restaurant's current menu and add new 
menu items by entering information such as the dish name, description, course, and price.

The application was was developed for Part 2 of the POE and enhanced in Part 3. 

## Features Include:
- Viewing all menu items.
- Displaying menu with their: dish name, description, course, and price.
- Adding a new menu item.
- Displaying an error message when required information is missing.
- Displaying confirmation when an item has successfully been added to the menu.
- Displaying newly added items under "Added Menu Items".
- Editing menu items and updating their details.
- Deleting menu items.

## Input Validation
- Validating that the dish name, description and price is entered.
- Requiring the user to select a course.
- Preventing invalid, zero and negative prices.
- Restricting prices to a maximum of 2 decimal places.
- Displaying meaningful error messages when invalid/incomplete information is entered.

## Search and Filter
- Searching for menu items using full or partial dish names.
- Filtering menu items according to their course: Starter, Main Course, Dessert.
- Combine search and course filtering.
- Displaying a message when no matching menu items are found.

## Menu Statistics
- The total number of menu items.
- The total number of each course type: Starter items, Main Course items, Dessert items.
- The average price of each course type: Starter items, Main Course items, Dessert items.

## Changes Implemented from Part 2
- Improved menu management by allowing the Chef to edit and delete menu items.
- Improved validation to prevent invalid, zero, negative prices and prices with more than two decimal places.
- Added separate success messages for adding and updating menu items.
- Added Search functionality by dish name.
- Added filtering by course type.
- Added total number of menu items.
- Added the average price for each course type.
- Improved menu cards, button placement and navigation.

## Design:
The application uses a warm restaurant-inspired colour palette.

The main colours in the app are: 
- Burgundy (#7A263A)	  - Header, primary buttons and headings
- Terracotta (#C96A4A)	- Add button and prices
- Cream	(#FFF8F0)	      - Main background
- White	(#FFFFFF)	      - Menu cards and input fields
- Dark Grey	(#2B2B2B)	  - Main text
- Grey	(#6B6B6B)	      - Descriptions and placeholder text
- Light Beige	(#E5D8CC)	

The design uses rounded cards and buttons to create a clean and modern mobile interface.
Clear Add, Edit, Delete, Save and Cancel buttons. 
Scrollable Menu Content. 
Safe-area handling to improve screen layout.
