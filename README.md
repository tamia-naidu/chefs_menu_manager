# 📱 Chefs Menu Manager

## App Description:
The Chefs Menu Manager App is a mobile application developed using React Native and Expo.
The application allows chef Christoffel to view the restaurant's current menu and add new 
menu items by entering information such as the dish name, description, course, and price.

## Features Include:
- Viewing the current menu items.
- Displaying menu with their: dish name, description, course, and price.
- Adding a new menu item.
- Displaying an error message when required information is missing.
- Displaying confirmation when an item has successfully been added to the menu.
- Displaying newly added items under "Added Menu Items".

## Design:
The application uses a warm restaurant-inspired colour palette.

The main colours in the app are: 
- Burgundy (#7A263A)	  - Header, primary buttons and headings
- Terracotta (#C96A4A)	- Add button and prices
- Cream	(#FFF8F0)	      - Main background
- White	(#FFFFFF)	      - Menu cards and input fields
- Dark Grey	(#2B2B2B)	  - Main text
- Grey	(#6B6B6B)	      - Descriptions and placeholder text
- Light Beige	(#E5D8CC)	

The design uses rounded cards and buttons to create a clean and modern mobile interface.
